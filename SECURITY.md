# Security Policy

shield-go installs git hooks that scan commits for secrets, so integrity of the
binary and the hook installation matters.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/chinmaymjog/shield-go/security/advisories/new>

You can expect an initial response within a few days. Please include affected
version, reproduction steps, and impact.

## Supported versions

Only the latest release receives security fixes.
